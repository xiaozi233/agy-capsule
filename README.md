## 功能

- **内联胶囊**：嵌入输入框底栏，按当前会话与模型动态读取真实上下文上限（如 `256k` / `512k`，未发起首轮前显示 `0 / --`），实时显示 Context 占比与 5h / Weekly 剩余配额。
- **Token 构成明细**：悬停查看 `Turn0`、`Read`、`Think`、`Write` 分段占比与 Token 用量。
- **上下文样式切换**：设置 → Appearance 可选择数字或双层圆环。圆环模式隐藏底栏数字，外圈表示上下文占用比例，内圈表示当前上下文中的缓存命中比例；缓存满 3 分钟变黄、满 4 分钟变红。悬停仍可查看完整明细，未知上下文上限以虚线圆环表示。
- **生成速度**：参考 [agy-tool](https://github.com/justhil/agy-tool) 的统计口径，底栏显示综合速度（输出 Token 含思考 ÷ 首 Token 等待与流式生成总耗时，如 `42.1 tok/s`），悬停速度胶囊查看流式速度（回复 Token ÷ 流式耗时）和首 Token 延迟 `TTFT`。新请求尚无统计时保留上一条完成记录，并在悬停面板标注 `prev.`，无有效记录时显示 `-- tok/s`；窄屏自动折叠，仍在上下文悬停面板查看。
- **设置面板**：`⋮` → Extensions 里的 **agy-capsule** 页面。上下文 / 速度 / 5 小时 / 周额度可独立开关；上下文、速度、额度三组可分别放在官方左右控件之间，靠左或靠右，不插入官方按钮组。在 Layout 中拖动排序或跨侧移动，也可用上下箭头调整同侧从左到右的顺序。设置持久保存并即时应用，连续操作会合并更新，位置动画从当前画面平滑衔接。
- **缓存过期提醒**：距上一轮满 3 分钟变黄倒计时（`~1m`），满 4 分钟变红标记 `Cache` 过期。
- **多模型配额面板**：自动匹配底栏当前模型（如 `Gemini`、`Claude`、`Argon`、`Carbon`），悬停查看各分组 5h 与周配额剩余比例及重置倒计时。
- **窄屏自适应折叠**：底栏变窄时逐级退让（先隐藏速度，再隐藏周配额，再依次只保留配额与上下文图标，最后省略号压缩模型名），保留悬停弹窗并避免重叠。
- **官方样式同步**：沿用官方控件的字体、图标尺寸、按钮高度与主题颜色，组件间不加分隔线。左侧浮窗贴齐组件左边缘，右侧浮窗贴齐右边缘；靠边自动避让，持续悬停和数据刷新时保持稳定，支持键盘与减少动态效果设置。
- **昼夜自适应 & 跨版本兼容**：直接复用宿主 CSS 变量；通过原生 Sidecar 与 CDP 挂载，不改客户端源码，客户端升级后直接使用。

## 安装

1. 将 [`agy-capsule`](./agy-capsule) 文件夹复制到 Antigravity 插件目录：
   - **Windows**: `%USERPROFILE%\.gemini\config\plugins\agy-capsule`
   - **macOS / Linux**: `~/.gemini/config/plugins/agy-capsule`
2. 在 Antigravity 的 **Plugins** 面板启用 **agy-capsule**。

## 声明

- **缓存过期提示仅供参考**：缓存状态（3 分钟预警 / 4 分钟过期）系根据距上一轮对话的时间间隔本地估算，实际命中情况以服务端为准。
- **测试环境与反馈**：目前仅在 **Windows** 环境下完成测试，欢迎在 **macOS** 环境下测试并反馈问题或提交 PR。
